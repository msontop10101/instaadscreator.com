# Insta Ads Site Builder - design handoff files

Open any .html file in a browser. They are static reference mockups exported from the design canvas,
with inline styles exactly as designed. Links between screens work.

- seller-mobile/   8 phone screens (390 x 844 frame)
- seller-desktop/  4 fluid desktop screens (designed at 1440)
- admin/           Admin.html (desktop), AdminMobile.html, AdminMobileReview.html
- ad-page-templates/  the 4 generated ad page templates (Luxe, Soft, Tech, Street)
- tokens.css       colour, font and radius tokens for the app and the 4 templates

Full spec (components, screens, states, accessibility): see the Developer Handoff doc.
Placeholders in [brackets] (e.g. [Brand], [PRICE], [7] days) are still to be decided.
Image areas are labelled placeholders; numbers on analytics/admin screens are sample data.
